# OMA MORI 玛卡饮品｜中国大陆版网站

简体中文静态站点，共 5 页。文案按《广告法》《食品安全法》思路重写：**不作任何保健功能表述、不使用绝对化用语、不使用消费者证言与满意度数据**。

## 页面

| 文件 | 页面 |
| --- | --- |
| `index.html` | 首页 |
| `about.html` | 关于玛卡（植物与成分背景） |
| `features.html` | 原料与工艺 |
| `ingredients.html` | 成分与规格 |
| `usage.html` | 饮用方式与标示 |

与港澳版的差异：删除「产品功效」「真实见证」「健康专栏」三个栏目，删除 98.8% 满意度、见效时间、性功能与生育暗示、医疗用语与绝对化用语；改以「成分与规格」「常见问题」「科普专栏」三页承接内容。科普专栏不介绍产品、不连结购买页，如需保持中立性，后续新增文章请沿用此原则。

## 上线前必须补齐

页脚的主体与备案公示区块已注释掉，见每页 `</footer>` 前的 HTML 注释。在大陆正式上线前请取消注释并填入真实信息：公司全称、营业执照注册号、食品经营许可证、境内代理商与地址、客服电话、ICP 备案号、公安联网备案号。备案号公示是大陆经营网站的必备项。

联系页的小红书账号名仍是 `【请填写】`，请补上。二维码图片位于 `assets/qr-wechat.png` 与 `assets/qr-xhs.png`，已做黑白化与留白处理并验证可扫描（微信指向公众号链接，小红书指向 xhslink 分享链接）；日后更换账号务必换图后再扫一次确认。

页面内仍有 `【请填写】` 标记（成分与规格页的部分添加量、联系页的渠道与开票信息、常见问题的配送规则），请按实际资料补上。

`features.html` 中关于浓缩倍数与专利的表述，须与供应商书面资料及有效专利证书一致；大陆广告中提及专利必须标明专利号与专利种类，无法举证的请删除。

`usage.html` 的营养成分表由原标示换算（1 千卡＝4.184 千焦），NRV% 按 GB 28050 参考值计算并取整，须以境内检测报告与中文标签复核。

联系表单目前为静态，需接入表单服务，并按《个人信息保护法》补充隐私政策链接与勾选同意。

## 技术说明

纯静态 HTML，无框架、无外部脚本、无外部字体，全部使用系统字体（苹方／微软雅黑／思源黑体），在大陆访问不依赖任何境外资源。

托管于大陆服务器须先完成 ICP 备案；备案期间网站无法访问。
